# Netdata UI Icon Reference

Source-derived from `src/components/icon/iconsList.js` and `src/components/icon/styled.js`.

## Usage

```jsx
import { Icon, iconsList } from "@netdata/netdata-ui"

<Icon name="alarm" size="small" color="primary" />

const allIconNames = Object.keys(iconsList)
```

## Icon Props

| Prop | Default | Behavior |
|---|---|---|
| `name` | required | Key in `iconsList`; unknown names render `null`. |
| `size` | inferred | `small -> 14px`, `medium -> 16px`, `large -> 24px`. If omitted: names ending `_s` use `small`, names ending `_l` use `large`, otherwise `medium`. |
| `width`, `height` | from `size` | String overrides for SVG dimensions. |
| `color` | none | Theme color/path via `getColor`; emits SVG `fill`. |
| `hoverColor` | none | Theme color/path via `getColor`; emits hover `fill`. |
| `rotate` | none | Numeric multiplier; source emits `transform: rotate(rotate * 90deg)`. |
| `disabled` | false | Opacity `0.4` and `pointer-events: none`. |
| `margin`, `alignSelf`, `cursor`, `sx` | none | Composed from source mixins / `@styled-system/css`. |
